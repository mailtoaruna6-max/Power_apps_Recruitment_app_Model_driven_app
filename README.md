# Power_apps_Recruitment_Management_app_Model_driven_app
This is a Recruitment Management App built in Power Apps (Model-Driven) to streamline the hiring process.
Home Page (Welcome Screen)

Displays a Welcome Page for users

Provides easy navigation to:

Roles (Job Openings)

Applications (Candidate Applications)

Contacts (Candidate/Recruiter details)
